# 1File1Tool

**Un file. Uno strumento.** Una raccolta di progetti completi e funzionanti, ciascuno realizzato in un singolo file (per esempio un'app HTML autonoma).

La pagina è statica e non richiede framework, dipendenze o build: è il file `index.html` pubblicato direttamente con GitHub Pages.

## Strumenti inclusi

- **[TaHoRe Effect](https://marcorzzn.github.io/TaHoRe_Effect/)** — genera immagini “Tap to Reveal” per X. [Repository](https://github.com/marcorzzn/TaHoRe_Effect) · [File unico](https://github.com/marcorzzn/TaHoRe_Effect/blob/main/index.html)
- **[QuantificatORE di CFU](https://marcorzzn.github.io/QuantificatoreCFU/)** — converte CFU in ore di studio e aiuta a pianificare gli esami. [Repository](https://github.com/marcorzzn/QuantificatOREdiCFU) · [File unico](https://github.com/marcorzzn/QuantificatOREdiCFU/blob/main/index.html)

## Pubblicazione su GitHub Pages

In **Settings → Pages**, scegli **Deploy from a branch**, seleziona `main` e la cartella `/ (root)`. La pagina verrà pubblicata all'indirizzo `https://marcorzzn.github.io/1F1T/`.

## Aggiungere uno strumento

Modifica `index.html` e aggiungi una scheda con:

1. nome e descrizione dello strumento;
2. repository e link al file singolo che contiene l'app;
3. link alla demo funzionante;
4. badge `1 file` e tag descrittivi.

Includi solo strumenti utilizzabili e completi, non semplici snippet o progetti che richiedono più file per funzionare.
